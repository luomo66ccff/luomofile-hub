Albums

相册与共建

相册接口使用本站登录会话。写入请求需要同源 Origin，且账户已验证邮箱；现有 API Key 不会自动获得相册权限。

GET/api/albums?scope=public公开发现；mine / joined 需要登录。
POST/api/albums创建个人或共建相册。
POST/api/albums/{id}/items加入自己拥有的图片，显式确认展示授权。
PATCH/api/albums/{id}/items/{file_id}说明、排序、审核或本人展示授权，逐项检查权限。
POST/api/albums/{id}/invitations由创建者邀请已有账户，对方接受后生效。
{"title":"一起记录风景","kind":"shared","view_policy":"restricted","contribute_policy":"restricted","listed":false,"review_required":true}

图片可以加入多个相册，原图仍属于上传者。相册公开、原图下载和图床直链分别授权；移出或删除相册不会删除原图。图片上传的 auto 策略使用私有图片存储，直链仍需主动生成。

认证与分享

将 API 密钥通过 Authorization: Bearer lfk_xxx 请求头发送。密钥范围由签发时的 scope 决定，完整密钥仅显示一次。

原文件直链与相册授权独立。上传默认不产生公开直链；相册不会自动包含旧文件。

POST/api/v1/files/upload

上传文件

以 multipart/form-data 发送文件，用 purpose 归类用途，用 generate_link 明确控制是否开启直链。

curl -H "Authorization: Bearer lfk_xxx" \
  -F "file=@example.png" \
  -F "purpose=image" \
  -F "generate_link=false" \
  {{ base_url }}/api/v1/files/upload
GET/api/v1/files

文件列表

curl -H "Authorization: Bearer lfk_xxx" \
  {{ base_url }}/api/v1/files
GET/api/v1/files/{file_id}

文件详情

curl -H "Authorization: Bearer lfk_xxx" \
  {{ base_url }}/api/v1/files/lf_xxx
POST/api/v1/files/{file_id}/link/generate

开启公开直链

开启后，持有直链的人可以读取原始文件。私有文件不能开启直链。

curl -X POST -H "Authorization: Bearer lfk_xxx" \
  {{ base_url }}/api/v1/files/lf_xxx/link/generate
POST/api/v1/files/{file_id}/link/revoke

吊销直链

原地址会停止访问。相册展示仍按独立授权判断。

curl -X POST -H "Authorization: Bearer lfk_xxx" \
  {{ base_url }}/api/v1/files/lf_xxx/link/revoke
DELETE/api/v1/files/{file_id}

删除原始文件

所有相册关联与图床直链同时失效。

curl -X DELETE -H "Authorization: Bearer lfk_xxx" \
  {{ base_url }}/api/v1/files/lf_xxx
GET/api/v1/storage/stats

存储统计

curl -H "Authorization: Bearer lfk_xxx" \
  {{ base_url }}/api/v1/storage/stats
